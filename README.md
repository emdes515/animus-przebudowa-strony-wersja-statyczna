# Fundacja ANIMUS — Wersja Statyczna

Nowoczesna, w pełni statyczna wersja strony internetowej **Fundacji ANIMUS — Centrum Edukacyjno-Szkoleniowe**.
Projekt zrealizowany w oparciu o czysty HTML5, Tailwind CSS oraz JavaScript.

## Struktura podstron
- index.html - Strona główna z prezentacją misji, statutowych celów i kluczowych obszarów
- bout.html - O fundacji, zespół i statut
- projects.html - Katalog zrealizowanych i trwających projektów
- single-project.html - Szczegółowe dossier wybranego projektu
- knowledge.html - Baza wiedzy, raporty i artykuły
- single-article.html - Artykuł merytoryczny / publikacja
- contact.html - Dane teleadresowe, formularz kontaktowy i numery telefonów

## Wdrożenie
Projekt przystosowany do natychmiastowego hostingu na platformach takich jak **Vercel**, Netlify czy GitHub Pages.
